# Contract: Release Process

## Triggers

- `push` of a tag matching `v*.*.*`.
- `workflow_dispatch` with input `tag` (an existing tag).
- Nothing else builds on macOS.

## Version gate — `scripts/release/check-version.sh <tag>`

- Strips the leading `v`; compares with `version` in `src-tauri/tauri.conf.json`,
  `[workspace.package].version` in `Cargo.toml`, and `version` in `package.json`.
- Exit 0 when all match. Exit 1 otherwise, printing one line per mismatch:
  `version mismatch: tag 0.2.0, src-tauri/tauri.conf.json 0.1.0`.
- Exit 2 on a tag that is not `vMAJOR.MINOR.PATCH`.

## Secrets (repository)

| Name | Use |
|---|---|
| `TAURI_SIGNING_PRIVATE_KEY` | update archive signing; passed through `env` only |
| `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` | its password |
| `GITHUB_TOKEN` | built-in; `permissions: contents: write` on the release job only |

The release job fails before building when `TAURI_SIGNING_PRIVATE_KEY` is empty:
`missing secret TAURI_SIGNING_PRIVATE_KEY; see README "Releasing"`.

## Release assets

| Asset | Required |
|---|---|
| `Sonata_<version>_universal.dmg` | yes |
| `Sonata.app.tar.gz` | yes |
| `Sonata.app.tar.gz.sig` | yes |
| `latest.json` | yes, uploaded last |

## Manifest — `latest.json`

Generated by `node scripts/release/latest-json.mjs --version <v> --notes-file <f> --sig-file <f> --url <archive-url> [--date <iso>]`.

```json
{
  "version": "0.2.0",
  "notes": "<release body>",
  "pub_date": "2026-10-30T12:00:00Z",
  "platforms": {
    "darwin-aarch64": { "signature": "<contents of .sig>", "url": "https://github.com/DuarteVn/sonata/releases/download/v0.2.0/Sonata.app.tar.gz" },
    "darwin-x86_64":  { "signature": "<same>",            "url": "<same>" }
  }
}
```

Rules: `version` without `v`; `signature` is the `.sig` file contents trimmed; `pub_date` RFC 3339
UTC; the script exits 1 on an empty signature or a non-https URL.

## App side

- Endpoint: `https://github.com/DuarteVn/sonata/releases/latest/download/latest.json`.
- Public key: `plugins.updater.pubkey` in `src-tauri/tauri.conf.json`.
